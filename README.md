# Aizen RP Bot

Отдельный Telegram-бот только для игровых RP-команд. Административных команд и функций модерации здесь нет.

## Общая база с ботом Айзен

Бот использует ту же PostgreSQL-базу, что и основной репозиторий `Amina-Recruitment-Bot`.

Внутренний идентификатор игрового профиля — кастомный `users.id`. Числовые аргументы игровых команд трактуются только как кастомный ID. Telegram ID может поступать от Telegram Bot API и использоваться только как технический ключ для сопоставления входящего update с записью пользователя; он не должен использоваться как игровой идентификатор, отображаться в профиле или приниматься в аргументах игровых команд. Также используется общая таблица `command_access`. Не создавайте отдельную базу для RP-бота.

## Переменные окружения Bothost

- `BOT_TOKEN` — токен нового RP-бота из BotFather.
- `DATABASE_URL` — тот же PostgreSQL URL, который использует основной бот Айзен.
- `OWNER_TELEGRAM_ID` — Telegram ID владельца; значение должно совпадать с основным ботом.
- `LOG_LEVEL` — например, `INFO`.

Не добавляйте токены и пароль базы в GitHub. Используйте переменные окружения Bothost.

## Запуск

Команда запуска: `python main.py`.

Зависимости: `pip install -r requirements.txt`.

## Команды

- `профиль` — показать свой игровой профиль.
- `профиль 100024` — показать профиль по кастомному ID.
- `покормить @username` — покормить участника.
- `покормить` в ответ на сообщение — покормить автора сообщения.
- Вместо username можно указать кастомный ID пользователя. Telegram ID в аргументах команд не принимается.
- Следующая строка необязательна, максимум 20 символов; поддерживаются обычные и Telegram Premium Emoji.
- `мдк` — показать только доступные вызывающему игровые команды.

Доступ RP-команд настраивается через ДК основного бота Айзен. Шкала: 0 — всем, 1–5 — с указанного ранга и выше, 6 — запрещено всем. Настраивать ДК может только владелец.

## Важно для групп

Добавьте бота в группу. Чтобы он видел команды без слеша и обычные реплаи, отключите Privacy Mode через BotFather: `/setprivacy` → `Disable`.

## Telegram Premium Emoji

Бот сохраняет custom emoji entities исходного сообщения и передаёт их при отправке ответа. Telegram разрешает ботам отправлять custom emoji в сообщениях, если владелец бота имеет Telegram Premium; если отправка не разрешена, бот отправит текст с обычным emoji fallback.
